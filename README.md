Student Registration Form with MongoDB

🎓 Student Registration Form – Full Stack Web Application

📌 Project Description

Student Registration Form is a simple full stack web application built using HTML, CSS, JavaScript, Node.js, Express.js, and MongoDB.

This project allows users to enter student details through a registration form and store the data in a MongoDB database using a backend API.

The application demonstrates frontend-backend integration, form handling, API requests, and database connectivity.

🚀 Features

✅ Student registration form
✅ Collect student details
✅ Gender selection using radio buttons
✅ Course selection using dropdown menu
✅ Form validation using JavaScript
✅ Store student data in MongoDB
✅ Backend API using Express.js
✅ Stylish user interface using CSS
✅ Reset form after successful submission
✅ MongoDB Compass database integration

🔄 Application Flow
User opens the student registration form.
User enters student details.
JavaScript collects form input data.
fetch() sends data to backend API.
Express.js server receives the request.
MongoDB client connects to database.
Student data is inserted into MongoDB collection.
Success message is displayed.
Form fields are reset automatically.
